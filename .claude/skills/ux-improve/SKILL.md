argument-hint: "<항목 ID | next | status>"

`docs/UX-IMPROVEMENTS.md`는 UX 개선 백로그다. 각 항목은 ID(`P0-1`, `R-1` 등), 체크박스, 개선안·구현 위치·기술 제약을 가진다. 인자: $ARGUMENTS

- `status`: 문서를 읽고 우선순위별 완료/미완료 현황과 남은 항목을 요약한다. 구현하지 않는다.
- `next`: 미완료 항목 중 P0 → P1 → R(제거) → P2 → P3 순, 같은 등급은 번호순으로 첫 항목을 고른다. 고른 항목을 알려주고 진행한다.
- 항목 ID: 해당 항목을 구현한다. 이미 `[x]`면 알리고 멈춘다.

구현 시:

1. 항목의 개선안과 구현 위치를 읽고, 문서 작성 이후 코드가 바뀌었을 수 있으니 실제 코드를 확인한다. 기획이 현재 코드와 맞지 않거나 범위가 크면 구현 전에 사용자와 범위를 맞춘다.
2. 구현하고 필요한 테스트·스토리를 추가한다.
3. `pnpm test`, `pnpm build` (UI 변경이면 `pnpm build-storybook`도)를 통과시킨다.
4. 통과하면 문서의 해당 항목을 `- [x]`로 바꾼다. 구현 중 기획과 달라진 점이 있으면 항목 아래에 짧게 메모한다.
5. 바뀐 파일, 검증 결과, 다음 추천 항목을 보고한다.
