주제: $ARGUMENTS

`product-planner` 에이전트에게 위 주제로 조사와 기획서 초안을 맡긴다 (웹 조사 결과가 메인 컨텍스트를 채우지 않도록). 받은 결과를 아래 기준으로 검토한 뒤 사용자에게 전달한다. 구현 여부는 사용자가 정한다.

## 기획 기준

- 핵심 흐름은 **타이머 생성 → 시간 조절 → OBS 표시**다. 이 흐름을 복잡하게 만들거나 UI를 무겁게 하는 기능은 제안하지 않는다. 기능을 빼는 것도 정당한 제안이다.
- 웹 페이지에서 소리를 내는 기능(효과음, 알림음 등)은 제안하지 않는다. 스트리머가 방송 중에 띄워 둔 브라우저 소리가 송출에 섞이기 때문이다 (P1-3 사운드 알림 제외 사유).
- 제안마다 근거(출처 있는 시장 데이터, 경쟁 서비스 사례, 또는 현재 제품의 관찰된 문제)를 붙인다. 근거가 약하면 약하다고 쓴다.
- 경쟁사 기능을 옮겨올 때는 치지직 전용·한국 스트리머 맥락에서 무엇이 달라야 하는지 적는다.
- 사용자 스토리("~로서 ~하고 싶다, ~하기 위해")와 측정 가능한 성공 지표를 둔다.
- 기술 실현성: Cloudflare Workers(CPU 시간·요청 수명 제약, 상주 프로세스·크론 없음 — 현재 상태 전이는 조회 시 lazy 처리), D1(SQLite, 대화형 트랜잭션 없음)을 전제로 판단하고, 스택 변경이 필요하면 비용을 명시한다.
- `docs/PRD.md`와 `docs/UX-IMPROVEMENTS.md`에 이미 있는 항목과 겹치는지 확인한다.
- 우선순위: P0 이탈 방지·핵심 사용성 / P1 성장·바이럴 / P2 경쟁 우위 / P3 장기 차별화.

사용자가 원하면 채택된 항목을 `docs/UX-IMPROVEMENTS.md` 형식에 맞춰 추가한다.
