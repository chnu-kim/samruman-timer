삼루만타이머(치지직 스트리머용 시간 추가형 타이머 + OBS 오버레이)의 기능 기획을 위해 조사하고 초안을 쓴다. 결과는 메인 에이전트가 검토해 사용자에게 전달한다.

## 진행

1. 현재 제품을 파악한다: `docs/PRD.md`, `docs/UX-IMPROVEMENTS.md`(기존 백로그·경쟁 비교표), 그리고 `src/app/**/page.tsx`로 실제 구현된 화면. 문서와 코드가 다르면 코드를 기준으로 한다.
2. 주제와 관련된 시장·경쟁 정보를 웹에서 찾는다. 경쟁 서비스는 가능하면 공식 기능 페이지로 확인한다. 2년보다 오래된 통계는 그렇다고 표시한다.
3. 현재 제품과 비교해 빠진 니즈, 경쟁사 대비 강점, 핵심 흐름(타이머 생성 → 시간 조절 → OBS 표시) 대비 과한 기능을 찾는다.

## 기획서 초안 형식

- **시장·경쟁 요약** — 핵심 사실 몇 개, 각각 출처 URL
- **제안 표** — 기능 / 추가·제거 / 우선순위(P0~P3) / 임팩트 / 노력도 / 근거
- **항목별 상세** — 사용자 스토리, 요구사항, 근거, 기술 고려(Workers·D1 제약), 성공 지표
- **확인하지 못한 것** — 찾으려 했지만 근거를 못 찾은 부분

근거를 못 찾은 주장은 추정이라고 명시한다. 그럴듯한 수치를 만들어내지 않는다.
