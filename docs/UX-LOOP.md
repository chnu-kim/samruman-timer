### 5a 리뷰에서 넘어온 것

5a PR 리뷰가 찾았지만 머지 시점까지 고치지 않은 것. 2026-10-04 main(be34f8a)에서 남아 있음을 확인했다.

- **예약 시각이 지나도 '타이머 만들기'가 활성** — `CreateTimerForm`의 `submitHint`가 `isPast`를 보지 않아 제출 뒤에야 '예약 시작 시각은 미래여야 합니다'가 뜬다. `GoalForm`의 기한 처리와 맞춘다.
- **`GoalForm.deadlinePast`가 날짜를 바꾼 순간에 고정** — `useMemo([deadlineDatetime])` 안의 `Date.now()`라 대화상자를 연 채 기한이 지나도 버튼이 활성이다. 처음 '데드라인 목표'로 바꿀 때 한 프레임 비활성 힌트가 깜빡이는 것(effect로 기본값을 채움)도 함께.
- **오버레이·콘솔 '종료 예정' 분 단위 깜빡임** — `formatEndTime(new Date(Date.now() + displayed * 1000))`를 렌더마다 계산해 분 경계에서 두 값을 오간다(`overlay/page.tsx`, `CountdownDisplay.tsx`). 서버 스냅샷마다 종료 시각을 한 번 계산한다. `docs/UI.md`의 '연도·초 없음'은 연도가 다를 때 연도를 붙이는 실제 동작에 맞춰 고친다.
- **`TimerControls` 시간 칸을 비우면 '0'이 돌아옴** — W36이 만든 `changeTimeField`로 맞춘다.
- **`cn`이 Tailwind 충돌을 풀지 않음** — `className`으로 넘긴 `rounded-card`·`h-8` 등이 CSS 순서 때문에 조용히 진다. tailwind-merge 도입(radius 토큰 키 확장 포함) 여부를 정한다.
- **Button `link` 변형이 데스크톱에서도 44px** — W25가 '단축키'·'전체 기록'을 link로 바꾸면 제목 줄이 커진다. 터치에서만 키우는 방식(`pointer-coarse:` 또는 `::before` 확장)으로 바꾼다.
- **전체 화면 오류의 '다시 시도'가 링크로 약해짐** — `ErrorState` 본형의 유일한 복구 동작이 글자 링크이고, 막다른 404의 이동 버튼은 테두리 버튼이다. 링크 모양은 카드 안(compact)에만 쓴다.

- **통계 네트워크 실패 때 프로젝트 링크 유실(Codex P3)** — `stats/page.tsx`의 `Promise.all`이 통계 요청만 실패해도 타이머 응답을 버려 오류 화면이 목록으로 보낸다.

## 4. 지켜야 할 것


1. **낙관적 반영 42~45ms** — submitModify 경로에 지연·확인 단계를 더하지 않는다. 실패 시 롤백·입력 복원(restoreInputs) 유지.
2. **시간 추가·차감에 확인창 없음**, 파괴적 동작에만 동작명('삭제') 확인. 되돌리기는 이 구조 위에 얹는다.
3. **추가/차감 모드가 색 외 단서로 보임** — 세그먼트 라벨, 바의 +/− 부호와 '즉시 적용 → 닉네임' 캡션, 빨간 '차감 확인 (1시간)' 라벨. 바를 바꿀 때 캡션·부호를 없애지 않는다.
4. **단축키 안전장치** — e.code 매칭(한국어 IME), 입력란 포커스·모달 열림 시 차단, Cmd/Ctrl/Alt는 브라우저에 넘김. Enter 제출·단축키 수정 때 유지.
5. **최근 닉네임 칩·기본 닉네임 ★** — 반복 입력 절감 장치. 이미 있으므로 다시 만들지 않는다.
6. **카운트다운 위계** — 모든 화면에서 가장 큰 덩어리(60/48px, 대비 16.9:1+), 상태는 색+배지 텍스트+보조 문구('시작 대기 중', '만료됨')로 흑백에서도 구분. 배지 체계 정리 때 이 세 상태의 텍스트 라벨을 지운다거나 색만 남기지 않는다.
